# About the Author

**Kshittiz Kumar** is a senior software engineer with more than nine years of experience building distributed systems, data platforms and cloud services.

## The path to this book

He wrote his first program in grade 7, in Java, using the BlueJ editor. In grades 11 and 12 he learned C++, and during his B.Tech in Computer Science and Engineering at GGSIPU in Delhi he took a course on the internals of Java 7. The handwritten notes he made in that course are where this book began.

His first job, at **Aricent** in Gurgaon, was in Java and Java EE: he built JEE, REST and AngularJS modules for a network management system and received the company's Team Excellence Award. He then earned a Master of Computer Science at **North Carolina State University**, interning at **PayPal**, where he built a Java tracer for real-time service monitoring.

At **FactSet** he worked on large-scale data pipelines and services in Go and Java, including redesigning a C++ service in Java that ran eight times faster. Since 2022 he has been a senior software engineer at **Microsoft** on Azure Cosmos DB, working on backup and restore for some of the largest databases in the cloud.

Along the way he has written production software in C, C++, C#, Go and Python. Java was his first language, and it remains his first love. *A Hike from Java 7* is his tribute to it.
