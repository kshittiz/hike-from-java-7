# About the Author

**Kshittiz Kumar** is a senior software engineer with more than nine years of experience.

He wrote his first Java program in grade 7, in the BlueJ editor, and Java has been his favorite language ever since. During his bachelor's degree, a course on Java's internals produced the handwritten notes this book grew from. He has since written software in C, C++, C#, Go and Python, but Java remains his first love. *A Hike from Java 7* is his tribute to the language.
